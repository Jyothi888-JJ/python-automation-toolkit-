# Automatic File Sorting & Directory Organization

This project demonstrates a simple **Python automation script** that automatically organizes files into separate folders based on their file extensions.

## What This Script Does

1. Scans a specified directory.
2. Checks each file's extension.
3. Creates folders for different file types.
4. Moves files into the appropriate folder.
5. Skips unsupported file types.

### File Organization

| File Type | Destination Folder |
| --------- | ------------------ |
| `.pdf`    | `docs`             |
| `.txt`    | `text`             |
| `.jpg`    | `images`           |

## Technologies Used

* Python
* `os` module
