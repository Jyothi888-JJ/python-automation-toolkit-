# Python Automation Toolkit

A collection of practical Python automation scripts focused on DevOps, system administration, cloud operations, monitoring, file management, and everyday automation.

## Projects

| #  | Project                         | Description                                                   |
| -- | ------------------------------- | ------------------------------------------------------------- |
| 01 | Kubernetes Weather Auto-Scaling | Uses weather API conditions to trigger Kubernetes pod scaling |
| 02 | Web Scraping                    | Extracts H1, H2 and H3 headings from websites                 |
| 03 | Email Automation                | Sends customized emails with PDF attachments                  |
| 04 | File Organizer                  | Automatically sorts files based on their extensions           |
| 05 | Customer Support Chatbot        | Simple rule-based chatbot using NLTK                          |
| 06 | Server Health Monitor           | Monitors HTTP services and sends Slack alerts                 |
| 07 | Folder Backup                   | Creates timestamped ZIP backups                               |
| 08 | File Cleanup                    | Removes files older than a specified number of days           |
| 09 | YouTube Downloader              | Downloads videos using yt-dlp                                 |
| 10 | Git Repository Sync             | Automatically clones or pulls Git repositories                |

## Technologies Used

* Python
* Requests
* BeautifulSoup
* Kubernetes
* kubectl
* NLTK
* Slack Webhooks
* Git
* yt-dlp

## Security

Secrets such as API keys, passwords, application passwords, and webhook URLs should never be committed to GitHub.

Use environment variables or a secrets manager for sensitive credentials.

## Disclaimer

These scripts are educational automation examples. Test scripts in a controlled environment before using them in production.
